# How we write notes

- One topic per note. Link generously: `[[` finds any note by its name.
- Meeting notes start with the date, as in `2026-09-29 Weekly sync`, so they sort.
- Tag what is still open with #open, and remove the tag once it's done.
- Ask in a comment, not in the text: select the words, press «Comment on selection», and resolve the thread once it's answered.
- Comments are stored inside the note, as HTML comments, so they travel with the file.
