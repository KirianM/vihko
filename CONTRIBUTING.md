# Contributing

Thanks for taking an interest in vihko.

## Issues are welcome

- **Something doesn't work:** open an issue with the bug report template. Say
  which version you run (`vihko --version`, or Preferences → Account → About),
  how you run it (Docker, which volumes and reverse proxy if any), what you did,
  what you expected and what happened. The log (`docker compose logs vihko`)
  helps; remove anything private from it first.
- **An idea or a question:** open an issue with the «Idea» template.
  [ROADMAP.md](ROADMAP.md) says what's planned.

## Pull requests

vihko doesn't accept pull requests for now. If you'd like to change something,
open an issue to talk about it instead.

## Security

Never report a vulnerability in a public issue. [SECURITY.md](SECURITY.md) says
how to report it privately.

## Forks

vihko is free software under the [AGPL-3.0](LICENSE): you may run, study,
change and share it. If you run a changed version as a service for others,
the license asks you to offer them its source.
[DEVELOPMENT.md](DEVELOPMENT.md) explains how to build, test and release it.
